# Optional large-printer STL

`keyboard_tray_full_325mm.stl` is the same keyboard fixture fused into one piece.

- Mesh envelope: approximately 325 x 157 x 11 mm.
- Recommended clear build area: at least 335 x 165 mm; allow more if using a brim or skirt.
- This file does **not** fit the QIDI Plus4's 305 x 305 x 280 mm nominal build volume in any flat rotation.
- Use the standard two-piece tray instead when the slicer reports any edge or toolhead-clearance conflict.
