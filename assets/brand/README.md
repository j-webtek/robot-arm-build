# Tactevra brand assets

Repository-native SVG assets for GitHub and documentation. The path connects
intent to a target; it is an abstract brand symbol, not a safety certification.

- `tactevra-banner.svg`: dark, self-contained README wordmark and tagline.
- `tactevra-mark.svg`: square path-to-target symbol.

Use the supplied colors and proportions. Retain legible alt text. Do not use the
mark as an operational status indicator or imply third-party endorsement.
The banner uses system fonts; it does not bundle a font file or external resource.

These original repository assets follow the root [Apache-2.0 license](../../LICENSE).
Trademark clearance is not established by their inclusion. Follow the
[brand guide](../../docs/brand/BRAND_GUIDE.md) for wording and compatibility rules.
