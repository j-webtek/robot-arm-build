# Corrected 00G-S1 plate — readable labels v2

Load **00G-S1_ABS_board_splice_fit_tests_REPAIRED_LABELS_v2.3mf** from this folder instead of the original 00G-S1 plate. The original was preserved, but has disconnected triangle indices and should not be printed as supplied.

## What changed

- All four packaged meshes have shared vertex connections. Direct raw-XML validation reports zero open edges, zero nonmanifold edges, consistent winding and one watertight solid per object. No automatic repair is used to obtain these validation results.
- BOARD / 18.65 identifies the board gap on a new outboard label tab. M6 identifies the nut-pocket block.
- SPLICE is larger on the collar's existing external wing. The overlapping arrow was removed.
- TEST is on an added end tab outside the truss test envelope. Insert the opposite, un-tabbed end into SPLICE, until the near-end bolt hole aligns. Do not try to push the label tab through the collar.
- Wide-stroke Arial Black lettering is raised 1.2 mm (six 0.20 mm layers), using 7.5–9 mm font sizes. Actual capital height varies by glyph.
- The small snap nut retainer is intentionally unlettered and dimensionally unchanged. It is the only small loose piece; do not add text to its mating surfaces.

The board gap, nut channel, collar body, bolt bores, and truss test envelope have passed CAD difference checks. The inserted test coupon has no modeled interference with the collar. Added tabs enlarge the overall coupon footprints, not their functional fits. All four original print transforms are retained and the revised layout still leaves at least 20 mm between object bounding boxes for the prescribed brims (within numerical tolerance).

## How to load

1. Start a fresh QIDI plate/project so the old parts are not duplicated.
2. Open the corrected 3MF. It contains four geometry objects, not printer or filament settings.
3. Select **RoCell 00G-S1 ABS Rapido Structural 0.20 v1** and the existing ABS Rapido filament preset.
4. Keep 100% scale, stored orientation/placement, supports off, and the 10 mm outer-only brim. Do not auto-arrange or run automatic mesh repair.
5. Re-slice from the new geometry; do not reuse the old G-code.
6. Verify QIDI no longer reports open edges. If any floating-region warning remains, inspect that specific layer before printing. Native QIDI slicing has not been verified for this revision; its short bridges still require toolpath/physical review.
7. Save separately as **00G-S1_REPAIRED_LABELS_v2_QIDI_native_v01.3mf**.

The 0.20 mm geometric layer screen found no new unsupported islands above its 0.1 mm² threshold. This is not a simulation of extrusion or proof of successful ABS bridging. No printer was started.
